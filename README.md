# XR-IT releases

Download location for XR-IT installers, shared with partners who do not have access to the
main (private) `trans-realities-lab-org/XR-IT` repository.

This repository holds **no source code**. Releases here are mirrored from the main repository by
the `mirror-release` workflow, one selected release at a time.

## Downloads

See the [Releases](https://github.com/trans-realities-lab-org/xr-it-releases/releases) page.

Each release attaches a single installer:

- `XRIT.Client.Setup.exe` — XR-IT Client (Runtime + Manager)
- `XRIT.Orchestrator.Setup.exe` — XR-IT Orchestrator (Runtime + Manager)

The release notes for each version are copied from the main repository.
